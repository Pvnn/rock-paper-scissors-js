# Rock-Paper-Scissors

A simple web-based Rock-Paper-Scissors game built with HTML, CSS, and JavaScript. This game allows users to play Rock-Paper-Scissors against a computer and includes features like score tracking and auto-play functionality.

## Features

- Play Rock-Paper-Scissors against the computer.
- Track wins, losses, and ties.
- Auto-play mode to automatically play rounds at regular intervals.
- Reset score functionality with a confirmation prompt.
- Keyboard shortcuts for ease of use.
